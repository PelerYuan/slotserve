### Added

- **Inbox for everyone**: every notification now lands in an in-app inbox first (`GET /api/me/notifications`), then
  goes to chat platforms. Members see their own events; admins also get alerts and to-dos, so nothing is lost when
  no chat platform is set up.
- **Health checks**: `/api/health` lists every check (`checks[]`: database, disk, inference engine, GPUs, Docker,
  storage, chat platforms, backups, background tasks, stored secrets, ...); `?strict=true` answers 503 while one is
  failing. Admins are alerted once when a check fails and again when it recovers. `/metrics` adds
  `slotserve_check_status` and `slotserve_backup_age_seconds`; `slotserve doctor` runs the same checks from the
  command line (exit code 1 on an error).
- **Backup bundles**: the daily backup is a folder with the database, the generated secret key, the SSH host keys
  and a manifest; `backup_target` copies it off the machine (a mounted NAS path or a managed storage), and failed or
  stale (> 36 h) backups raise an alert. `slotserve restore <bundle>` puts one back; the next start compares it with
  Docker and the disk and shows a report. Workspaces and kept environments are not part of a backup.

### Changed

- The daily backup runs at `backup_hour` (default 3:00 local time) instead of 24 hours after the previous one. The
  admin backup download still returns the database file.

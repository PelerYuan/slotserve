### Added

- Failed model loads explain themselves: the admin runtime view and the load history carry a diagnosis (likely cause and next steps in English and Chinese, the matching log lines) for common failures such as a port already in use, GPU out of memory, a missing or non-executable engine, CUDA mismatches, missing/damaged/unsupported model files, Docker and image pull problems and NFS/SMB mount failures; unrecognized failures keep the exit code and the log tail.

### Added

- **Next step on the Overview**: one card at the top, chosen by what matters now: My work (environments and bookings running now or starting within 24 hours, with +1 h, Open and Copy ssh), the setup checklist for admins, or "Start here" for newcomers (call a model, open a dev environment, book the whole GPU; ticked from real activity, can be dismissed, remembered per account). Admins see what waits for them (bookings and sign-ups to approve, system errors) in one line above it.
- **Inbox for everyone**: a bell with an unread count in the header. Members get the news about their own work; admins also the admin messages, with a count on the Admin menu item.
- **Call a model in the browser (Playground)**: chat with a free, running model from the Overview or the Models page without creating a key, next to the same request as Python, cURL and JavaScript. "Copy code to run locally" makes a key named `playground` (90 days) on request and fills it into the code.
- **Model availability badge**: "Callable now", "Available after booking" or "In use by … until …", the same on the Overview, Models, the Playground and Quick booking (`models` in `GET /api/status`).
- New API keys can expire (30, 90 or 365 days); the dialog of a new key shows ready-to-run code with the key filled in.
- One-time "you can also…" suggestions after a first success (at most one on screen, never shown twice).

### Changed

- A GPU taken by a whole-GPU booking or a dev environment shows "In use" on the Overview instead of a stopped model server.
- The login page's demo shows mostly successful traffic and dev environments in the browser.

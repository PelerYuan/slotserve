### Changed

- Dev environments page: open an environment in three steps (tool → GPU or not → Open). VS Code in the browser without a GPU is the default and needs no SSH key; the SSH key step appears inline only for terminal / SSH environments (paste a public key, the commands to make one per system, or a key pair made in the browser). Each environment card is a workbench: time left, +1 h (says why when the next hour is taken), End in two steps with "Save as image" first, live GPU use and GPU-hours, web interfaces opened through one-time links, its own SSH Host alias and host key, ports, and files and storage (where /workspace lives, usage, why a storage is unavailable). Shared environments have Join / Leave. Switching VS Code, the desktop or JupyterLab to a direct port asks for confirmation first.

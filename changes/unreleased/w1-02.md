### Security

- Dev environment web interfaces on the shared web port are kept apart more strictly: a page of one environment can no longer act in another one opened in the same browser. One browser uses one person's environments (or one shared environment) there at a time; opening another switches over. Admins opening someone else's environment confirm it first (audited) and get access for an hour. Apps that break under these rules can be helped with **Settings → Web interface compatibility mode**.
- The web proxy no longer keeps cookies set by the apps in environments between requests.

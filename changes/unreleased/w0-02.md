### Security

- **Launch arguments are governed**: members may only use each engine's tuning flags and point models into the models folder, a model library or a Hugging Face repository id; other flags go to the admins as a request (**Models** shows it, admins approve or reject), flags that can run code or write files (`--trust-remote-code`, `*-file`, `*-path`, `--log*`…) need an explicit confirmation even from admins, and the custom engine is admin-only. Catalog one-click deploys are unaffected.

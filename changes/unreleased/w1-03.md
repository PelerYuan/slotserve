### Added

- **Settings registry**: every setting carries its group, level (basic / advanced / expert), dependencies and safety marks; `PUT /api/admin/settings?dry_run=true` previews who and which bookings a new quota, longest booking, booking horizon or approval rule affects (existing bookings are always kept), `?notify=true` tells those people, and settings changes can be undone from the audit log.
- **Extra hours per person**: admins can give one person temporary extra weekly hours (until a date, with a reason) on top of the weekly quota.
- The audit log records old and new values of settings (secrets only as a fingerprint), the client address, sign-ins and failed sign-ins, new API keys, SSH keys and backup downloads; it can be filtered by person, action and target and exported as CSV.

### Security

- Settings that can run commands as root on the host (engine commands, the dev environment storage directory, the port forwarder image) are recorded as sensitive changes and announced to all admins. `SLOTSERVE_DEVENV_STORAGE_DIR` refuses system directories such as `/etc`, `/root`, `/var/lib/docker` or `/proc`.

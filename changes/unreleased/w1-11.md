### Added

- **Inside dev environments**: `SLOTSERVE_*` variables (end, environment, lane, GPUs, machine, checkpoint directory), a login banner (time left, `/workspace` usage, how to call a model) and `OPENAI_BASE_URL` pointing at a new container-side gateway (`http://slotserve-gw:8002/v1`, only the `/v1` API). Booked and CPU-only environments get their own LLM key, exported as `OPENAI_API_KEY` in login shells; shared environments get none. Settings **Platform context in environments** and **Environment LLM key**; `SLOTSERVE_DEVENV_GATEWAY_PORT` / `SLOTSERVE_DEVENV_GATEWAY_HOST`.

### Security

- The environment key is a 0600 file (`/run/slotserve/llm-key`), never in the container's environment, and is revoked when the environment stops. Images saved from an environment (and kept environments' snapshots) no longer contain the environment key, the SSH host key, root's password hash or the values of SlotServe's variables (`docker commit` used to copy them).

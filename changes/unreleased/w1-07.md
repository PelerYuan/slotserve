### Security

- Root-equivalent settings (engine commands, the dev environment storage folder, the port forwarder image) and admins' changes of model launch arguments now need the password entered within the last 5 minutes; the web UI asks for it in a dialog and repeats the action.

### Added

- **Admin → Overview** starts with a setup checklist that ticks itself (engine, GPUs, models, invites, and optional dev environments, chat, backups) and ends with the system health table: every check with its evidence, buttons, a diagnosis card for recognised errors (also on the runtime monitor) and dismissing with a reason.
- **System settings** opens on policy cards of the basic settings; all settings are one click away, expert ones folded. Search finds settings by label in both languages, variable name or keyword; "changed only" filter; each card or group saves on its own after a preview of who and which bookings a change affects, optionally telling those people. Every setting has its history with undo, and the read-only deployment parameters are listed.
- **Invite links** under Admin → Users: create one (expiry, number of sign-ups, optional approval), copy the link and a ready-to-post group message in English or Chinese, see who signed up, revoke it, approve or reject waiting sign-ups. The link opens the sign-up form with the invitation already filled in.
- Per-person **extra hours** ("10 more hours a week until Friday, thesis defence") and a "this week" column with near/over filter under Admin → Users.
- **Audit log** filters by person, action or area, target and dates, with a CSV of the same selection; settings changes read "before → after" and can be undone from there.
- **Settings → Signed-in devices**: see where your account is signed in and sign out one or all other devices.

### Changed

- The admin sections are grouped (Run, People, Communication, System) so they fit on one line at 1440 px, with a list on narrow screens; "Requests" is now "Request log".
